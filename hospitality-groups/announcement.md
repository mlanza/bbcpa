# Men's Hospitality Groups Pilot Announcement

Men,

Are you getting the kind of relationship you hope for from the men you meet at church?

If you often feel unknown, if you wish you knew more people, or if you simply do better in smaller settings, this may be for you.

We are piloting a new Hospitality Groups concept with the Men's Group first. The goal is to create small, interest-based gatherings that help people be known, enjoy one another, and build room for conversation around a shared interest.

This is a pilot. I will treat participation as one measure of whether this is actually wanted. If it gets used, that tells us something. If it does not, that tells us something too.

You can respond in one of two ways:

1. **Sign up for an event**
2. **Volunteer to host an event**

If you host, you are free to offer something you already enjoy. For example, if you like football and want to watch a game with a few others, that works.

If you want to host an event, give me at least **2 weeks notice** and I will set it up for you. Please send:

1. A description of the event you have in mind, and what you will provide or what people should bring
2. The start and end time, plus the full location address
3. The maximum number of attendees you want

That cap matters. We are using Planning Center and RSVPs on purpose so events stay small and leave room for conversation, not just turnout.

The point of hospitality is not just to do an activity together. It is to make space for a shared interest plus actual conversation.

Initially, this pilot is just for the men. If it proves useful, we can talk later about opening the lane to other groups.

If you want to host something, or if an event sounds like a good fit, let me know.
